# Golestan Tea Homepage Clone

A clone of the [Golestan](https://www.golestan.com) company homepage, built as my first React project for learning purposes.

> **Note:** This is a practice project and is not affiliated with Golestan. All brand names, logos and images belong to their respective owners.

## Tech Stack

- [React](https://react.dev)
- [Vite](https://vitejs.dev)
- [Tailwind CSS](https://tailwindcss.com)
- [React Icons](https://react-icons.github.io/react-icons/)
- Some font awesome free icons

## Features

- Responsive sticky navbar with dropdown menus
- Hero section
- Product sections rendered from a data file
- News and videos sections
- Social responsibility section with social media links

## Getting Started

Make sure you have [Node.js](https://nodejs.org) installed, then:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Go into the project folder
cd golestan-tea

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build for Production

```bash
npm run build
```

The output will be in the `dist` folder.
